b. How does the chromosome size distribute? Plot a graph that helps to visualize this by using ggplot2 package functions.

summary(chromosome$length_mm)
##    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
##   16.00   27.75   45.50   43.83   55.00   85.00
ggplot(chromosome, aes(x = length_mm)) +
  geom_histogram(bins = 15, fill = "steelblue", color = "black") +
  labs(
    title = "Distribution of Chromosome Size",
    x = "Size",
    y = "Count"
  ) +
  theme_minimal()

The chromosome +size is from 16 to 85, with mean 43.83 and median 45.50. As shown in the histogram, most chromosomes have sizes between approximately 15 and 65, with a concentration around 40 and 50.

c. Does the number of protein coding genes or miRNAs correlate with the length of the chromosome? Make two separate plots to visualize these relationships.

p1 <- ggplot(chromosome, aes(y= protein_codinggenes, x= length_mm)) + 
  geom_point(alpha=0.50, size=3, color = "blueviolet") +
  geom_smooth(method=lm, color = "red") + 
  labs(x="Chromosome size", y = "Protein coding genes") + 
  theme_minimal() 

p2 <- ggplot(chromosome, aes(y= mi_rna, x= length_mm)) + 
  geom_point(alpha=0.50, size=3, color = "darkgreen") +
  geom_smooth(method=lm, color = "red") + 
  labs(x="Chromosome size", y = "miRNAs") + 
  theme_minimal() 

p1 + p2

Plots show that both the number of protein coding genes and miRNAs increase when the length of the chromosome increase.
